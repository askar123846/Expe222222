# Expense Tracker

**Автор:** [Шарипов Аскар]

## Описание

Приложение для отслеживания личных расходов с фильтрацией, подсчётом суммы за период и сохранением данных в JSON‑файл.

## Функциональность

* Добавление расходов с указанием суммы, категории и даты.
* Фильтрация по категории и периоду дат.
* Подсчёт общей суммы расходов за выбранный период.
* Сохранение и загрузка данных.
* Визуализация данных в виде таблицы.
