# Book Tracker (Трекер книг)

**Автор:** Иван Иванов

GUI-приложение на Python (Tkinter) для ведения списка прочитанных/планируемых книг.
Позволяет добавлять книги в таблицу, фильтровать по жанру и количеству страниц, а также сохранять/загружать данные в JSON.

## Возможности
- Добавление книги с полями:
  - Название
  - Автор
  - Жанр
  - Количество страниц
- Таблица со списком книг
- Фильтрация:
  - по жанру
  - по диапазону страниц (мин/макс)
- Сохранение и загрузка данных в JSON
- Проверка ввода:
  - страницы — целое положительное число
  - текстовые поля не пустые

## Требования
- Python 3.8+
- Tkinter (обычно уже установлен вместе с Python)

## Запуск
```bash
python book_tracker.py
