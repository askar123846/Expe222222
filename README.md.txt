# Expense Tracker (Трекер расходов)

**Автор:** Иван Иванов

GUI-приложение на Python (Tkinter) для учёта личных расходов: добавление записей, таблица, фильтрация по категории и датам, подсчёт суммы за период, сохранение и загрузка данных в JSON.

## Возможности
- Поля ввода: **Сумма**, **Категория**, **Дата (YYYY-MM-DD)**
- Кнопка **«Добавить расход»** добавляет запись в таблицу
- **Фильтрация**:
  - по категории
  - по диапазону дат (с/по)
- **Подсчёт суммы** расходов за выбранный период (с учётом фильтров)
- **JSON**: сохранение и загрузка данных
- Проверка ввода:
  - сумма — положительное число
  - дата — формат `YYYY-MM-DD`

## Требования
- Python 3.10+ (подойдёт и 3.8+, если Tkinter установлен)
- Tkinter (обычно уже есть в стандартной поставке Python)
